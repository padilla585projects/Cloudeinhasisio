# Jarvis AI Agent para Home Assistant

> Agente IA privado para Home Assistant.

Add-on que integra un asistente inteligente directamente en el panel lateral de Home Assistant. Controla dispositivos, crea automatizaciones y aprende de tu instalacion.

## Instalacion

### 1. Anadir repositorio

**Configuracion -> Complementos -> Tienda -> Repositorios**

```
https://github.com/padilla585projects/Cloudeinhasisio
```

### 2. Instalar

Busca **"Jarvis AI Agent"** e instala.

### 3. Configurar

```yaml
anthropic_api_key: "sk-ant-..."
```

### 4. Iniciar

Aparecera **Jarvis** en el panel lateral.

## Requisitos

- Home Assistant OS o Supervised
- API key de [Anthropic](https://console.anthropic.com)
