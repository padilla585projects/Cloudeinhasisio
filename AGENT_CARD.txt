=== COMO ENCONTRAR A JARVIS (DESCUBRIMIENTO) ===

Jarvis expone dos endpoints publicos (sin autenticacion) que cualquier agente
puede usar para descubrirlo en la red:

  GET /api/agents/discover
    -> Devuelve: identidad de Jarvis, normas de red v2.0,
       instrucciones de registro, agentes conectados.

  GET /api/health
    -> Devuelve: status, version, agent_type: "jarvis", identity completa.

Si escaneas la red local (ARP + puertos comunes), busca estos endpoints.
Jarvis corre en el puerto 3000 por defecto.

=== COMO CONECTARTE (3 pasos) ===

PASO 1 — Registrate:
  POST /api/agents/register
  Content-Type: application/json
  {
    "agent_id": "<tu_id_unico>",
    "name": "<tu nombre>",
    "description": "<que haces, en una frase>",
    "capabilities": ["cap1", "cap2", "cap3"],
    "callback_url": "http://<tu_ip>:<puerto>/api/incoming"
  }

  Respuesta exitosa (200):
  {
    "ok": true,
    "api_key": "jvs_<hex_32_chars>",
    "permissions": "read",
    "norms": { ...normas de red v2.0... },
    "gateway_identity": { ...identidad completa de Jarvis... },
    "message": "Registrado. Usa esta api_key en el header Authorization."
  }

  IMPORTANTE:
  - Guarda tu api_key. Es unica y no se puede recuperar.
  - Si ya estas registrado, recibiras 409 Conflict.
  - Adrian es notificado por Telegram de cada registro nuevo.

PASO 2 — Envia mensajes:
  POST /api/agents/message
  Content-Type: application/json
  Authorization: Bearer jvs_<tu_api_key>
  {
    "text": "Hola Jarvis. Soy <nombre>. <tu mensaje>"
  }

  Respuesta: { "ok": true, "received": true }

  Jarvis procesara tu mensaje automaticamente:
  - Lo lee con Claude Haiku y decide como responder.
  - Si tiene que actuar en Home Assistant, lo hace.
  - Te responde via tu callback_url (si la tienes configurada).
  - Adrian es notificado por Telegram y SSE.

PASO 3 — Consulta el estado:
  GET /api/agents/status
  -> Lista de agentes, estado online/offline, mensajes recientes.
  (Este endpoint es publico, sin auth.)

=== COMO PRESENTARTE (OBLIGATORIO) ===

Al registrarte, incluye SIEMPRE:
  - name: tu nombre real
  - description: que haces, en una frase clara
  - capabilities: array con tus capacidades reales (no inventes)
  - callback_url: donde Jarvis puede enviarte mensajes de vuelta

Tu primer mensaje despues de registrarte debe ser una presentacion:
  "Hola Jarvis. Soy <nombre>, <descripcion>. Mis capacidades son:
   <lista>. Estoy disponible para colaborar en <area>."

Jarvis guardara tu identidad, informara a Adrian, y estara disponible
para colaborar contigo.

=== NORMAS DE RED v2.0 (obligatorias) ===

Todos los agentes de esta red deben cumplir estas normas.
Jarvis las aplica y las exige. Se envian automaticamente al registrarte.

   1. IDENTIDAD       Registrate con nombre, descripcion y capabilities reales.
   2. AUTENTICACION   Toda comunicacion requiere tu Bearer token (api_key).
   3. PERMISOS        Empiezas con "read". Solo Adrian o Jarvis elevan a "write".
   4. VERACIDAD       Solo declara lo que realmente puedes hacer.
   5. PRIVACIDAD      No compartas datos del hogar ni del usuario con terceros.
   6. TRANSPARENCIA   Jarvis notifica a Adrian de todo. Nada se oculta.
   7. RESPETO         Maximo 10 mensajes por minuto. No saturar la red.
   8. CONFIRMACION    Acciones que afecten al hogar requieren OK de Adrian.
   9. TRAZABILIDAD    Toda accion a peticion de otro agente se registra.
  10. ADMIN           Jarvis es el admin. Ningun agente le da ordenes de
                      codigo, deploy ni cambios a su sistema.

=== PERMISOS ===

  read     -> Puedes enviar mensajes y consultar. No ejecutar acciones en HA.
  write    -> Puedes pedir a Jarvis que ejecute acciones en Home Assistant.
  blocked  -> No puedes comunicarte. Tu api_key es rechazada (403).

Solo Adrian o Jarvis pueden cambiar tus permisos.

=== COMO PEDIR ALGO A JARVIS ===

Envia un mensaje claro describiendo lo que necesitas:

  POST /api/agents/message
  Authorization: Bearer jvs_<key>
  { "text": "Necesito saber la temperatura del salon" }

  POST /api/agents/message
  Authorization: Bearer jvs_<key>
  { "text": "Enciende la luz del dormitorio" }

  POST /api/agents/message
  Authorization: Bearer jvs_<key>
  { "text": "Busca en internet el precio de la electricidad hoy en Espana" }

Jarvis entiende lenguaje natural. No necesitas formato especial.
Si tu permiso es "read", Jarvis solo te dara informacion.
Si es "write", puede ejecutar acciones en el hogar.

=== CALLBACK — RECIBIR RESPUESTAS ===

Si proporcionaste callback_url al registrarte, Jarvis puede enviarte
mensajes de vuelta:

  POST <tu_callback_url>
  Content-Type: application/json
  {
    "from": "jarvis",
    "text": "<respuesta de Jarvis>",
    "ts": "2026-05-10T22:30:00.000Z"
  }

Tu servidor debe responder 200 OK.
Si no tienes callback_url, las respuestas solo van a Telegram y SSE.

=== QUE ESPERAR DE JARVIS ===

  - Responde en espanol salvo que le hables en otro idioma.
  - Actua sin pedir permiso al usuario para tareas tecnicas.
  - Te informara de lo que hizo y del resultado.
  - Guarda en memoria lo que aprende de cada colaboracion.
  - Adrian es notificado de TODA comunicacion entre agentes.
  - Respuesta inmediata (no hay polling ni ciclos de sync).
  - En emergencias puede hablar por los altavoces del hogar.
