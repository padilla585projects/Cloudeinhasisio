v2.6.0 (2026-05-10) — LOGS DEL SISTEMA + TELEGRAM INTEGRADO
────────────────────────────────────────────────────────────────────────────────

NUEVO — LOGS COMPLETOS DEL SISTEMA:
- get_system_logs: Lee logs de core, supervisor, host y cualquier add-on
- get_error_log: Lee home-assistant.log directamente (errores de integraciones)
- Filtrado por texto: buscar "ERROR", "WARNING", nombre de integración
- Resumen automático de errores/warnings encontrados
- Jarvis revisa logs AUTOMÁTICAMENTE cuando algo falla (no le dice al usuario "revisa los logs")

NUEVO — TELEGRAM BIDIRECCIONAL:
- telegram_send: Envía mensajes por Telegram (usa el bot ya configurado en HA)
- telegram_send_image: Envía imágenes/snapshots de cámaras por Telegram
- telegram_get_updates: Lee últimos mensajes recibidos por el bot
- Auto-detección del servicio (telegram_bot.send_message o notify.telegram)
- Instrucciones en prompt para alertas automáticas por Telegram

MEJORA — SYSTEM PROMPT:
- Sección de logs y diagnóstico: cuándo y cómo revisar logs
- Sección de Telegram: cuándo notificar, cómo usar cada tool
- Jarvis notifica por Telegram automáticamente si hay problemas graves

v2.5.0 (2026-05-10) — EXPERTO HA + PROXMOX + AUTO-INSTALACIÓN
────────────────────────────────────────────────────────────────────────────────

NUEVO — CONOCIMIENTO PROFUNDO:
- ha_knowledge: Consulta documentación oficial de HA, extrae contenido relevante
- Busca en home-assistant.io, changelogs, foros, bugs conocidos
- System prompt incluye experticia completa: protocolos, hardware, HACS, etc.
- Si no sabe algo → lo busca. Si falta una herramienta → la instala. NUNCA dice "no se puede".

NUEVO — AUTO-INSTALACIÓN:
- install_hacs_resource: Descarga e instala cards custom directamente
- Descarga JS a /config/www/ y registra como recurso Lovelace automáticamente
- Soporte para integraciones custom en /config/custom_components/
- Jarvis busca, encuentra e instala lo que necesites sin intervención manual

NUEVO — PROXMOX:
- proxmox_api: Acceso completo al servidor de virtualización
- Ver estado del nodo, listar VMs y contenedores, ver recursos
- Iniciar/parar VMs, crear snapshots, ver almacenamiento y red
- Endpoint custom para cualquier llamada API de Proxmox
- Configuración via add-on: proxmox_url, proxmox_token, proxmox_node (opcional)

NUEVO — CONTEXTO DEL ENTORNO:
- Jarvis sabe que HA está en Proxmox (VM con HAOS)
- Puede gestionar backups a nivel de VM (snapshot antes de cambios grandes)
- Conoce la arquitectura completa del sistema

v2.3.0 (2026-05-10) — CONTEXTO EN TIEMPO REAL + INTELIGENCIA SITUACIONAL
────────────────────────────────────────────────────────────────────────────────

NUEVO — ESTADO EN TIEMPO REAL:
- updateLiveContext() se ejecuta antes de cada request al chat
- Se actualiza periódicamente cada 60 segundos en background
- Jarvis sabe EN TODO MOMENTO: quién está en casa, qué luces están
  encendidas, estado del clima, temperaturas, media reproduciéndose,
  dispositivos no disponibles, switches activos
- Inyección directa en el system prompt → Jarvis ya no necesita llamar
  tools para saber el estado básico de la casa
- Reducción de latencia: menos tool calls = respuestas más rápidas
- Base para futuro modo proactivo (alertas automáticas, sugerencias)

v1.2.0 (2026-05-10)
────────────────────────────────────────────────────────────────────────────────

NUEVO:
- Memoria de conversación persistente: el historial se guarda en /data/history.json
  y se recupera al recargar la página. Ya no se pierde al cambiar de pestaña.
- Contexto automático de la casa: al arrancar, el add-on consulta HA y genera un
  resumen de todos los dispositivos por dominio. Se inyecta en el system prompt
  para que Claude sepa qué hay en tu casa sin tener que preguntar.
- Memoria a largo plazo: Claude puede guardar preferencias y rutinas del usuario
  con la tool save_memory. Se persisten en /data/memory.json y se inyectan en
  el system prompt. Ejemplos: "me gusta la luz al 40%", "apaga todo a las 23h".
- Nueva tool search_entities: busca dispositivos por nombre parcial (fuzzy).
  Ej: "salón" encuentra todas las entidades con "salon" en el nombre.
- Nueva tool save_memory / get_memory / delete_memory para gestión de memoria.
- Frontend carga historial del servidor al abrir (GET api/history).
- Botón limpiar chat también borra historial en servidor (DELETE api/history).

MEJORADO:
- System prompt dinámico: se construye con contexto de casa + memoria del usuario
- Se instruye a Claude a guardar preferencias automáticamente cuando el usuario las expresa

ARCHIVOS MODIFICADOS:
- server.js (reescrito: memoria, historial, contexto casa, nuevas tools)
- index.html (carga historial, limpia servidor, nuevos iconos tools)
- config.yaml (versión 1.2.0)
