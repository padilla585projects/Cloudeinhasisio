v3.1.0 (2026-05-10) — EQUIPO DE AGENTES + CONOCIMIENTO INDUSTRIAL
────────────────────────────────────────────────────────────────────────────────

NUEVO — EQUIPO DE AGENTES IA COLABORATIVO:
- Los agentes de Adrián son un equipo que puede mejorarse mutuamente
- Protocolo de mejora mutua: analizar, proponer, aprobar, aplicar
- Regla de oro: NUNCA modificar el código de otro agente sin aprobación
- Los agentes comparten descubrimientos, errores y soluciones entre ellos
- Comunicación via agent_communicate (HTTP/webhook)
- Toda propuesta entre agentes pasa por proactive_thought → Adrián decide

NUEVO — CONOCIMIENTO DE AUTOMATIZACIÓN INDUSTRIAL:
- PLCs: Siemens S7, Allen-Bradley, Schneider, Omron, Beckhoff, Wago
- Protocolos: Modbus TCP/RTU, OPC-UA, PROFINET, PROFIBUS, EtherNet/IP,
  EtherCAT, BACnet, MQTT Sparkplug B, CANopen, IO-Link, HART
- SCADA/HMI: Ignition, WinCC, FactoryTalk, Wonderware/AVEVA, Grafana
- Sensores: RTD, termopares, presión 4-20mA, caudal, nivel, vibración, proximidad
- Actuadores: VFDs, servos, válvulas proporcionales, cilindros neumáticos
- Redes OT: switches industriales, VLANs, firewalls IT/OT, DMZ
- Normas: IEC 61131-3, ISA-95, IEC 62443, ISA-88, NAMUR
- Control: PID, cascada, feedforward, ratio, split-range
- Seguridad funcional: SIL, IEC 61508/61511, parada de emergencia
- Industria 4.0: edge computing, digital twins, mantenimiento predictivo
- Integración en casa: Modbus→HA para inversores solares, VFDs para HVAC,
  sensores 4-20mA para piscinas/calderas, OpenPLC en ESP32

MEJORA — IDIOMA FORZADO:
- Jarvis SIEMPRE responde en español, sin excepción

v3.0.0 (2026-05-10) — AUTONOMÍA PROACTIVA + CREACIÓN DE ADD-ONS
────────────────────────────────────────────────────────────────────────────────

NUEVO — PENSAMIENTO PROACTIVO:
- Jarvis piensa por sí mismo cada 5 minutos (background loop)
- Analiza estado del sistema: dispositivos caídos, errores en logs, anomalías
- Genera pensamientos (suggestion, alert, action_request, optimization, creation)
- Prioridades: low, medium, high, critical
- High/critical se notifican automáticamente por Telegram
- Medium/low se muestran al abrir el chat (banner interactivo)
- proactive_thought tool: registra ideas y pide aprobación al usuario
- Endpoint /api/pending_thoughts para consultar y resolver pensamientos
- Botones aprobar/rechazar directamente en la UI del chat
- Sistema seguro: NUNCA ejecuta acciones destructivas sin aprobación

NUEVO — CREACIÓN DE ADD-ONS:
- create_addon tool: genera estructura completa de un nuevo add-on de HA
- Genera: config.yaml, Dockerfile, run.sh, código principal, build.yaml
- Soporta Node.js, Python y Shell como lenguajes principales
- Aplica licencia CC BY-NC-ND 4.0 automáticamente (blindaje)
- Los add-ons se crean en /share/addons_dev/[slug]/
- Listos para mover al repo y aparecer en la tienda de HA
- Mismos privilegios y protección que el add-on principal

MEJORA — SYSTEM PROMPT EXTENDIDO:
- Nueva sección "Autonomía Proactiva" con reglas claras
- Jarvis sabe qué puede hacer solo vs qué debe consultar
- Instrucciones para creación de add-ons
- Filosofía: autónomo pero leal, piensa y propone

MEJORA — FRONTEND:
- Banner de pensamientos pendientes al cargar el chat
- Botones inline para aprobar/rechazar cada pensamiento
- Iconos y labels para create_addon (🏗️) y proactive_thought (💭)
- Los pensamientos se eliminan del banner al resolverlos

TOTAL TOOLS: 34 (get_entities, search_entities, get_entity_state, call_service,
